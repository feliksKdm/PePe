# Voice Lab — CosyVoice 3 на своём Hugging Face Space

План: дублируешь готовый рабочий ZeroGPU Space на свой аккаунт (сборка уже
проверена, ничего не сломается), портфолио переключаешь на свой URL одной
строчкой. Дальше — кастомизация по желанию.

## Шаг 1 — HF PRO (ты решил брать)

1. Аккаунт: https://huggingface.co/join (подтверди почту).
2. PRO ($9/мес): https://huggingface.co/pro — даёт 25 мин H200/день,
   приоритет в очереди GPU и возможность доплаты сверх квоты.

## Шаг 2 — Дублируй Space (1 клик, ~10 минут сборки)

1. Открой https://huggingface.co/spaces/multimodalart/Fun-CosyVoice3-0.5B-zerogpu
2. Справа вверху: ⋮ (три точки) → **Duplicate this Space**.
3. В диалоге:
   - Owner: твой аккаунт
   - Space name: `voice-lab` (или любое)
   - Visibility: **Public** (иначе embed на сайте не заработает)
   - Hardware: **ZeroGPU** (подтянется автоматически)
4. Жди зелёный статус **Running** (первая сборка качает модель, ~10 мин).
5. Проверь прямо на странице Space: запиши 10 сек голоса, введи текст,
   сгенерируй.

## Шаг 3 — Подключи к портфолио (1 строка)

Твой embed-URL: `https://<username>-voice-lab.hf.space`
(дефисы вместо точек/подчёркиваний, всё в нижнем регистре — точный URL
виден в Space: ⋮ → Embed this Space).

В `src/constants/index.js` в записи `voice-lab` замени `src:` на свой URL —
и убери TODO-комментарий. Всё, инструмент работает на твоей инфраструктуре.

## Шаг 4 (опционально) — Кастомизация под свой бренд

В Space: Files → `app.py` → Edit. Безопасные изменения (не ломают сборку):

- Заголовок/описание Gradio-интерфейса → «Voice Lab — Feliks Altymyshov».
- Убери китайский UI-переключатель, если не нужен.
- Добавь свой пресет-голос: запиши 20–30 сек чистой речи, загрузи файл
  `my_voice.wav` в Space (Files → Add file) и сделай его дефолтным
  prompt-аудио в интерфейсе. Тогда демо «говорит твоим голосом» без
  загрузки референса.
- README.md Space: поставь `title: Voice Lab`, свои emoji/цвета.

Коммит в Space = автоматический ребилд (~2 мин, модель уже в кэше).

## Правила безопасности (уже показываются на странице инструмента)

- Клонируй только свой голос или голос с явного разрешения владельца.
- Синтетическое аудио нельзя выдавать за реальную запись человека.
- Референс-аудио посетителей не хранится дольше сессии Gradio.

## Как это работает (для собеседований)

- **Модель:** Fun-CosyVoice3-0.5B-2512 (Alibaba FunAudioLLM, Apache-2.0) —
  LLM-based zero-shot TTS: 9 языков, 18 диалектов, клонирование с 3–30 сек.
- **Инфраструктура:** HF ZeroGPU — serverless H200, слайс GPU выделяется
  на время вызова функции с декоратором `@spaces.GPU`. Квота списывается
  с посетителя, а не с владельца Space.
- **Фронт:** Gradio web-component (`<gradio-app src=…>`) внутри React-роута
  `/tools/voice-lab`; реестр инструментов в `constants/index.js` решает,
  что рендерить (custom-компонент / gradio-embed / roadmap).
